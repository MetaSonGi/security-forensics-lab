## 개인정보
- [ ] 이름, 이메일, 전화번호, 주소가 없다
- [ ] 회사명, 학교명, 근무처 정보가 없다
- [ ] 계정 ID, 닉네임(실계정), 프로필 사진이 없다

## 민감정보
- [ ] 비밀번호, 토큰, API 키, 쿠키, 세션 값이 없다
- [ ] 실제 공인 IP, 실제 도메인, 실제 서비스 이름/로그가 없다 (랩 IP와 샘플만 허용)
- [ ] 스크린샷에 알림, 파일 경로(사용자명 포함), 브라우저 탭, 북마크가 노출되지 않았다

## 파일 자체
- [ ] 디스크 이미지, 메모리 덤프, pcap 원본, evtx 원본을 커밋하지 않았다 (.gitignore 확인)
- [ ] 파일 메타데이터(EXIF 등)에 위치 정보가 없다
- [ ] 타인의 자료/데이터를 그대로 올리지 않았다 (출처 표기 또는 자체 작성)
